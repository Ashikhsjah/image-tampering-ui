# Image Tampering Detection (UI-Based)

This project detects edited regions in an image using traditional image processing techniques and highlights the tampered area.

## Features
- No ML / No DL
- Detects edited image regions
- UI-based application
- Runs directly on GitHub using Streamlit

## How It Works
- Edge detection
- Thresholding
- Contour analysis
- Region localization

## Run Online
Deploy using Streamlit Cloud.

## Technologies Used
- Python
- OpenCV
- Streamlit
